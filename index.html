🧬 What actually is a Space?

Every Space is just a git repo. A README.md frontmatter block configures the runtime — the SDK, the hardware, the title. That's it.

---
title: Spaces Capabilities Demo
emoji: 🧪
sdk: static          # gradio | docker | static
pinned: false
---

This very Space uses exactly that. Change sdk: and you change what kind of app HF builds and serves for you.

🛠️ The three ways to build a Space

Pick the SDK that fits the app.

🐍

Gradio

Python. The most common Space. A few lines of gr.Interface(...) gives you a UI + an auto-generated REST/MCP API. Supports ZeroGPU.

needs compute
📦

Docker

Any container, any stack. Streamlit, FastAPI, Node, Rust… full control via a Dockerfile. For when you outgrow Gradio.

needs compute
⚡

Static

Plain HTML/JS, or a built React/Vue/Svelte app. In-browser ML with WebGPU/WASM. Free for everyone — you're looking at one now.

free · no hardware

⚙️ Hardware tiers

Static needs none. Gradio & Docker run on compute and generally need a paid plan — with one big exception (ZeroGPU) for free accounts.

TierWhat it isFree account?
StaticNo server; browser does the work✓ unlimited
ZeroGPUOn-demand A10G-class GPU, per request✓ up to 2*
cpu-basic2 vCPU / 16 GB, always-on✗ paid plan
Dedicated GPUT4 → H200, billed hourly✗ paid plan

* Free personal accounts in good standing (verified email, > 30 days old) can host up to 2 ZeroGPU Gradio Spaces. Newer accounts can request a community grant.

✨ Things Spaces can do

🔌 Auto API + MCP

A Gradio Space is also a REST API and an MCP server — every function becomes a callable tool.

🔐 Secrets & env

Inject API keys as hidden secrets, or public config as env vars, at creation or later.

💾 Buckets

Spaces are stateless, but mount a bucket at /data for durable storage.

🧩 Embed anywhere

Every Space embeds as an iframe, and Gradio Spaces expose a JS/Python client.

🌐 Inference Providers

Proxy to Cerebras, Together, Fireworks… to run huge models with zero local VRAM.

👥 Community

Likes, discussions, duplication — anyone can fork your Space with one click.
